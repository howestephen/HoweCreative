# Portfolio image review - contact sheet triage

Reviewed against the Quiver benchmark. Dark site (#060707), silver/warm-white type, cinematic and restrained. Targeting Creative Technologist / Design Engineer roles at serious international firms.

## Benchmark: Quiver

Every one of Quiver's 16 frames is native 16:9 (1920x1080, with a few 1672x941 crops that read as the same ratio), so the contact sheet lays out as an unbroken grid with no size or chrome discontinuity anywhere on it. Nothing is a tool screenshot - every frame is a rendered shot of the same dark-fantasy archer world (hooded figure, glowing bow, single UI phone mock styled into the same palette), so the set reads as stills from one film rather than evidence scraped from a working folder. That is the bar: uniform frame, authored (not captured) content, one consistent lighting and palette system end to end.

These need to be either cut entirely or manually resliced by re-opening the page and taking fresh, purpose-shot crops of specific moments (hero, one feature section, footer) - the existing screenshot-tool captures cannot be salvaged by resizing or cropping alone within this file.
